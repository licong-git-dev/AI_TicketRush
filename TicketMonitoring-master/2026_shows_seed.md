## 大麦的硬伤（必读）

`Monitor_DM.py:140-175` 内置的 cookie 是仓库原作者 2024 年的，**100% 已过期**，不替换的话上面任何 itemId 都监控不到——只会在自检里抛错。

替换方法见 [`../抓包指南.md`](../抓包指南.md#2-大麦monitor_dmpy)：电脑 Chrome 扫码登录 `m.damai.cn` → F12 → Application → Cookies → 复制 `_m_h5_tk` / `cookie2` / `sgcookie` / `tfstk` 等到代码里。

## 猫眼怎么补 show_id

猫眼 H5 / 小程序的 show_id 在 URL 参数里。可行抓法（按难度递增）：

1. **App 分享链接**：进猫眼 App → 演出详情页 → 右上角分享 → 复制链接，URL 里 `id=XXXXX` 就是。
2. **小程序抓包**：用 Stream（Android）拦截 `wx.maoyan.com/my/odea/project/shows` 请求，body 里 `projectId` 就是。
3. **此仓库不能从公网猫眼站直接 grep**：show.maoyan.com 是 next.js 渲染，初始 HTML 里没有数据。

> 我（Claude）的沙箱出口 IP 已被 Alibaba 风控墙拉黑（`cloud_ip_bl`），search.damai.cn 接口直接 deny；
> 上面这份大麦 itemId 是从 Google 索引里反查的，不保证全部仍在售。
